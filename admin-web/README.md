# 衡弈纺织运营后台雏形

## 公共界面规范（2026-10-23）

`business-ui.css` 在原布局样式之后加载，按设计变量、按钮与表单、公共布局、页面适配的顺序组织。页面使用浅灰背景、白色卡片、浅灰字段和统一绿色主题；控件默认高 40px、圆角 8px，列表操作按钮高 32px。

按钮使用 `button-primary`（实色主要）、`button-secondary`（浅色普通）、`button-ghost`（透明辅助）、`button-danger`（浅红危险）。悬停、键盘聚焦、禁用和 `aria-busy` 加载反馈统一定义；保存操作通过 `setButtonBusy` / `withButtonBusy` 管理，保持原校验、接口、权限及保存流程。

公共样式覆盖工作台、面料、分类、案例、样卡申请、客户和首页配置。列表操作列固定右对齐，紧凑宽度下表格在卡片内滚动；弹窗统一标题、内容和操作区间距。页面隐藏状态遵循 `hidden` 属性，避免公共布局样式意外显示隐藏字段。

本地检查：`node --check admin-web/app.js`。视觉验收可通过本地服务查看各列表、新增面料、分类弹窗、案例编辑、申请/客户详情及首页配置。线上更新须同时发布 `index.html`、`app.js` 和新增的 `business-ui.css`；本次未执行部署。

这是一个无需安装依赖即可运行的电脑端交互原型，用于确认后台的信息结构、录入流程和视觉方向。

## 本地运行

推荐在项目根目录运行启动脚本；脚本会固定使用当前项目作为网站根目录，不受终端当前路径影响：

```powershell
.\start-admin.cmd
```

如果当前终端不在项目目录，也可以使用完整路径：

```powershell
& 'C:\Users\NUC\Desktop\面料微信小程序\start-admin.cmd'
```

浏览器打开：

```text
http://localhost:4188/admin-web/
```

## 已实现

- 运营工作台与样卡申请队列
- 面料列表、筛选、搜索、复制
- 面料长表单、必填校验和小程序实时预览
- 色数手动填写与色号范围自动生成
- 公共特色标签库、抽屉选择器、自由新增与相似标签提醒
- 顶部轮播图（4–6张）、详情图和多张电子色卡分别上传
- 图片拖动排序，并提供前移/后移按钮作为稳定操作方式
- 手机框内可滚动的完整详情预览
- 保存草稿与上架状态
- 系列、案例、客户的列表雏形
- 样卡申请状态推进
- 首页海报上传、当季热销关联、本期上新自动编排和最多 5 个成衣案例选择
- 首页配置单页管理与小程序手机框实时预览
- 面料、分类、图片与首页配置通过 `/api` 保存到自建服务器
- 浏览器 `localStorage` 仅作为服务器不可用时的临时展示兜底

## 原型边界

- 本地静态预览服务不包含 `/api`，需要连接项目 Flask 服务才能测试保存与图片上传。
- 系列、案例和客户目前以结构展示为主，后续补充完整编辑表单。
